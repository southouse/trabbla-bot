🇺🇸 *미국 여행 영어* Day 50
_주제: 쇼핑과 사이즈 문의 (3회차)_

*1. Where are the fitting rooms?*
탈의실이 어디예요?
💬 직원: In the back, past the shoes.
💡 탈의실은 fitting room 또는 dressing room이다.

*2. Does this run small?*
이거 작게 나와요?
💬 직원: A little. I'd size up.
💡 run small/large는 사이즈가 작게/크게 나온다는 뜻이다. size up은 한 치수 크게 고르는 것이다.

*3. Can you hold this for me?*
이거 좀 따로 보관해주실 수 있어요?
💬 직원: Sure, I can hold it until closing.
💡 잠깐 둘러보고 올 때 쓴다. 여기서 hold는 "따로 빼두다"라는 뜻이다.

*🔁 오늘의 패턴*

*Does this run ~ ?* — 이거 ~ 나와요?
· Does this run large? 이거 크게 나와요?
· Does this run true to size? 이거 정사이즈로 나와요?
· Do these shoes run narrow? 이 신발 좁게 나와요?

*What size is ~ ?* — ~는 몇 사이즈예요?
· What size is this? 이거 몇 사이즈예요?
· What size is a Korean 250 in US sizes? 한국 250이면 미국 사이즈로 몇이에요?
· What size is the kids' one? 아이용은 몇 사이즈예요?
